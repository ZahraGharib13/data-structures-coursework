# Data Structures Coursework

Python implementations and exercises from my Data Structures course.

This repository documents the data structures and algorithmic concepts I practiced throughout the course. Each folder contains a focused topic with source code or a Jupyter Notebook and a short explanation.

## Topics

- Stack
- Balanced-parentheses checking
- Queue and circular-array implementation
- Binary trees and tree traversal
- Heaps
- AVL trees
- Splay trees
- Recursive algorithms
- Dynamic programming

# Data Structure Basics

Introductory implementations from the Data Structures course.

## Covered Concepts

- Array-based Stack
- Stack operations: `push`, `pop`, `top`, and `is_empty`
- Balanced-parentheses checking with a stack
- Circular array-based Queue
- Queue resizing
- A linked stack with efficient middle-element removal

## Requirements

Only Python 3 is required. No third-party packages are used.

To view the notebook:

```bash
jupyter notebook simple_data_structures.ipynb
```

Jupyter is only needed to open the notebook interactively; the implementations themselves use the Python standard library.

## Notes

The original coursework notebook also contained unfinished experimental sections for a running median and a BST node. Those incomplete stubs were not included in this cleaned GitHub version. The completed data-structure exercises were retained and lightly cleaned for readability.
